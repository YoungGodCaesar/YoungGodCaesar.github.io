# Rener Llander Hanayon — Portfolio

A single-page, space-themed portfolio site for **Rener Llander Hanayon**,
BS Information Technology student at **Garcia College of Technology**.

## Features
- Animated starfield background (canvas, `requestAnimationFrame`, twinkling + parallax + shooting stars)
- Smooth scroll reveal animations, hover micro-interactions
- Fully responsive, keyboard-focus visible, respects `prefers-reduced-motion`
- Zero dependencies except Google Fonts — just open `index.html`
